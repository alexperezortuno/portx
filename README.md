# PortX

Provider-agnostic tunneling platform written in Go.

## Features

-   Multi-provider
-   Single binary
-   Open Source
-   Cloud Native
-   Extensible
-   Dashboard
-   Plugin architecture

  Tailscale    Planned
  PortXD       Planned
